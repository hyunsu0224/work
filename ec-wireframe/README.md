# EC ワイヤーフレームビルダー

**現在のバージョン: v2.10.0**

ブラウザでサーバーとして開き、ECサイトのローファイワイヤーフレームを **組み立て → ライブプレビュー → HTMLダウンロード** するツール。
出力物・UIは日本語専用（ローファイのグレーボックス、SP/PC 768px 分岐）。

## 公開ページ (GitHub Pages, 暗号化ロック)
静的ホスティングのためサーバー認証はかけられませんが、**ページ自体をAES-GCMで暗号化**して、パスワードなしでは開けないように配布します。
- URL: **https://hyunsu0224.github.io/work/** — アクセス時にパスワードを入力 → 復号されてビルダーが開きます。
- パスワード入力前はソースが **暗号文** のみ露出（ドキュメントにはsalt/iv/暗号文のみで、パスワード自体は含まれません）。
- ビルド/再配布:
  ```bash
  cd ec-wireframe && node build-static.mjs   # .wf-pass または WF_PASSWORD でパスワードを指定
  cd .. && git add docs && git commit -m "chore: rebuild public page" && git push
  ```
- 注意: ① リポジトリがpublicの場合、`src/` の原本もGitHubからそのまま読めます（公開ページのロックとは別）。コードまで隠すにはリポジトリをprivateに。② 暗号文はダウンロードしてオフラインで総当たり攻撃が可能なので、**公開配布用のパスワードは長く強力に** することを推奨します。

## パスワードロック (ローカルサーバーのBasic認証)
サーバーは **認証を通過する前はどのファイル（HTML・JS・CSS）も送信しません。** 初回アクセス時にブラウザ標準のログイン画面が表示され、通過してはじめてページ・ソースがロードされます。（ユーザー名は任意、パスワードのみ確認）

- パスワードの優先順位: 環境変数 `WF_PASSWORD` > フォルダ内の `.wf-pass` ファイル > デフォルト値（`wireframe`）
- **パスワードの変更**: `.wf-pass` ファイルの内容を任意の値で保存（このファイルは `.gitignore` によりコミットされません）。例は `.wf-pass.example` を参照。
  - または実行時に: `$env:WF_PASSWORD="任意のパスワード"; node server.js 8000`
- 認証を無効化: `$env:WF_NOAUTH="1"; node server.js`
- ⚠️ Basic認証はローカル（localhost）での利用が前提です。外部ネットワークに公開する場合はHTTPSが必要です。

## 使い方
1. 上部で **ページ種別**（top/list/detail/cart/mypage/lp）を選択 → 標準テンプレートが敷かれる
2. 左側の **コンポーネント** チップでセクションを追加、⧉複製 · ▲▼ · ✕削除、**⠿ ドラッグで並び替え**
3. 各セクションの **オプション**（列数・枚数・バッジなど）を調整 → 右側プレビューがリアルタイム更新
4. **表示対象**（PC+SP / PC / SP）でプレビュー幅を切り替え
5. **言語**（韓国語/日本語）トグル
6. **⬇ HTMLダウンロード** → `<ページ種別>-wireframe.html`（自己完結の単一ファイル）

header · footer · cookie-bar は全ページ共通で自動的に含まれます。

## 機能詳細
- **実動作スライダー/インタラクション**（プレビュー・ダウンロードファイル共通）:
  - hero = 実際のスライド（矢印・インジケーター・自動再生、hoverで停止）。オプション: **矢印表示 on/off**・自動再生・インジケーター・枚数。
  - 商品カルーセル（ランキング・おすすめ・関連） = **左右の矢印でスクロール（スライド）**。
  - 商品詳細ギャラリー = **サムネイル/矢印のクリックでメイン画像を切り替え**（枚数オプション）。
  - **タブクリック切り替え**: ランキングタブをクリックすると実際に該当パネルに切り替わる（カードのカテゴリもタブ名で）。
- **言語の一貫性**: ビルダーUI（オプションラベル・ボタンなど）は言語トグル（韓国語/日本語）に応じて **1つの言語のみ** で表示。出力物のECコンテンツラベルは日本のECサイト向けのため日本語固定、wf-note注釈のみ言語別。
- **注釈（コメント）モード**: セクションごとにコメント/スペックノートを入力（黄色い吹き出しでプレビュー表示）。上部の **注釈 ON/OFF** トグルで `wf-note`+コメントを一括表示/非表示 → **開発用（表示） ↔ クライアント用（非表示）**。ダウンロードファイルの右上にも `注記` トグルボタンがあり、受け取る側で切り替え可能。
- **編集の利便性**: ⧉複製（オプション・コメントごとコピー） / ⠿ドラッグ&ドロップで並び替え / セクション名をクリック→選択後にコンポーネントを追加すると **その下に挿入**（再クリック=解除、未選択時は末尾に追加）。
- **内容編集（ダミー→実データ）**: カテゴリグリッドタイルのラベル、カテゴリタイトル・件数、商品カードの商品名・カテゴリ・価格などをオプションから実際の値に → ローファイをミッドファイのスペックへ格上げ。空にするとダミーを維持。

## LP / 特集リッチコンポーネント
TOPと差別化されるLP専用ブロック。パレットから追加（全ページで使用可能）:
- **メディア+テキスト**: 片側に画像 ↔ 反対側にタイトル・説明・CTA（右下）。オプション: 画像の位置（左/右）、タイトル・説明・ボタンラベルの編集、**画像スライド枚数**（2枚以上で実動作スライダー）、**アニメーション**（なし/フェードイン/スライドアップ — スクロール進入時にリビール）。
- **特徴コラム**（3つのポイント） / **CTAバンド** / **FAQアコーディオン**（クリックで展開） / **利用の流れ STEP** / **お客様の声 VOICE**。
- アニメーションはIntersectionObserverベースのスクロールリビール + タイムアウト・noscriptフォールバック（必ず表示）。ダウンロードファイルでも動作。

## 元に戻す / やり直し (undo·redo)
- 上部の **↶ 元に戻す / ↷ やり直し** ボタン、ショートカット **Ctrl+Z / Ctrl+Shift+Z（=Ctrl+Y）**。
- 対象: **内容編集の履歴**（セクションの追加・削除・移動・複製・ドラッグ、オプション・コメント値、ページ種別・読み込み・初期化）。言語・表示対象・注釈表示のような画面設定は履歴から除外。
- 連続タイピングは **1つの項目にまとめられる**（0.5秒止まると確定） → 1回の元に戻すでその編集をまるごと取り消し。
- テキスト入力欄にフォーカスがあるときはCtrl+Zがブラウザ標準の元に戻すとして動作（文字単位）。ボタンは常に動作。
- 履歴はメモリ上のみ保持（最大100段階） — リロード時に初期化（自動保存された構成はそのまま残る）。

## 作業内容の保持（永続化）
- **自動保存**: 全ての変更がブラウザの `localStorage`（キー `ec-wf-state-v1`）に自動保存されます。ウィンドウを閉じたりリロードしても、**サーバーを再起動しても** 最後の構成がそのまま復元されます。（同じブラウザ・同じPCが前提）
- **💾 構成保存**: 現在の構成を `<ページ種別>-wireframe.wf.json` ファイルとしてエクスポート。複数案の保管・gitコミット・他のPC/人との共有用。
- **📂 読み込み**: 保存しておいた `.wf.json` を読み込んで構成を復元。
- **初期化**: 現在のページの標準テンプレートに戻します（自動保存も上書き）。

## 構造
```
index.html          ビルダーのエントリポイント
server.js           無依存の静的サーバー
styles/
  builder.css       ビルダーUIスタイル
  wireframe.css     出力物（ワイヤーフレーム）スタイル — 単一ソース、export時にインライン化
src/
  app.js            UIコントローラー（状態・プレビュー・ダウンロード）
  icons.js          コンポーネント別ミニ図解アイコン（インラインSVG） — パレット・セクション一覧用
  catalog.js        コンポーネント辞書（render関数） — demoマークアップと同一の出力
  templates.js      ページ種別ごとの標準セクション構成
  export.js         状態 → 自己完結HTMLの組み立て（共通ヘッダー/フッター/スクリプト）
  i18n.js           言語パック（ko/ja）: UI・wf-note・メタ
skill/              オリジナルのwireframe-generatorスキル（参照ドキュメント・根拠）
```

## 拡張方法

- **新しいページ種別**: `templates.js` の `PAGE_TYPES`・`templates`・`palette` + `i18n.js` の `pageTypes`
- コンポーネント/ルールの根拠は `skill/references/` を参照
