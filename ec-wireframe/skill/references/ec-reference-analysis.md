## 共通骨格 (3社一致)
1. **ヘッダー**: ロゴ + グローバルナビ(カテゴリ/ブランドor地域/特集/ニュース) + ユーティリティ(ガイド/FAQ/お問い合わせ) + 会員アクション(ログイン·新規登録·お気に入り·マイページ·カートバッジ·検索)。
2. **メガメニュー/ドロワー**: PC hover 展開 + `close/とじる`。SP ハンバーガードロワー。
3. **ヒーローカルーセル**。
4. **カテゴリグリッドナビ**(アイコンタイル)。
5. **ランキング**(カテゴリ/性別/地域タブ)。
6. **商品カルーセル**(新着/おすすめ/今売れた/NEW ARRIVALS)。
7. **特集/ニュースバナー群**。
8. **ファセット導線**(シーン・機能 / デザイン / エリア / ブランド)。
9. **フッター**: ガイド·コーポレート·法的表示リンク群 + SP/PC 切替 + コピーライト。
10. **クッキー同意バー**。

## URL 文法 (共通) — company-rules 1項の出典
- `c`=カテゴリ/ブランド、`r`=ランキング/リスト、`g`=商品、`e`=特集、`t`=トピック、`pages`=静的。
- `customer/`, `cart/`, `contact/`, `goods/search`。
- `?ismodesmartphone=on` SP 切替(Regal フッターで確認)。

## サイト別の特徴 (variant の根拠)
### FEILER
- グローバルナビのカテゴリアコーディオン + LOVERARY サブブランド(`/shop/c/c20/`)。
- 商品カード: NEWバッジ + Quick view + ♡ + `¥N（税込）`。
- ランキングをカテゴリ別(ハンカチ/バッグ/ポーチ) + LOVERARY で分離。
- variant 軸: 柄(パターン)·色·サイズ(ハンカチ 15~30cm)。
- サイド: CATEGORY / RECOMMEND / カラーから選ぶ(色チップ) / 最近見た商品。

### REGAL
- グローバルナビ多層: カテゴリ(MENS/WOMENS/KIDS/GOODS/CARE) + ブランド(ロゴグリッド) + ニュース + もっと見る + コーポレート。
- **SALE 表記の確定根拠**: `¥9,900（税込）30%OFF ¥6,930（税込）` → 定価の取り消し線 + OFF% + 割引価格。
- variant 軸: **サイズ**(靴は必須)、商品コードに色·サイズをエンコード(`gF07PCCA____BL___220`)。
- ファセット: シーン・機能 / デザイン(トウ形状) / ブランド。
- 決済手段バナー群(Amazon Pay/楽天/PayPay/d払い/Paidy…)。

### DISCOVER WEST mall
- グローバルナビのアンカー型: `#block_globalnav_category`, `#block_globalnav_area` + `とじる`。
- 地域(エリア) 軸が強い: 北陸/近畿/山陰/せとうち/九州(`/shop/c/c10~c50/`)。
- ランキング: カテゴリ別 + **地域別** の二重。
- カルーセル: 今売れた商品 / あなたへのおすすめ / 新着。
- variant 軸: 食品特性(のし·配送日·冷蔵冷凍·セット)。
- 遅延ロード `img/usr/lazyloading.png` を全面使用。
