# components.md — コンポーネント辞典

ワイヤーフレームを組み立てる「ブロック語彙集」。各コンポーネントは `wireframe.css` の `wf-*` クラスでレンダリングする。
ページ制作時はここからブロックを取り出し、`page-templates.md` の順序どおりに配置する。

> **表記規約**
> - 状態・インタラクションはグレーボックスの上に `<span class="wf-note">…</span>` 注釈で明示する。
> - オプションは各コンポーネントの `オプションフラグ` で指示書から on/off する。
> - 画像の位置は必ず `wf-box wf-box--img`（斜線）で表示 → 実装時に差し替え箇所が一目でわかる。

## 1. header
- **役割**: サイト最上部に固定。ブランド認知 + 全ページ共通ナビゲーションの入口。
- **構成**: ユーティリティナビ（ガイド/FAQ/お問い合わせ/会員）· ロゴ · グローバルナビ · 会員アクション（検索/お気に入り/マイページ/カートバッジ）。
- **状態・動作**: PC=sticky 固定。SP=ハンバーガーのみ表示、ユーティリティ・グローバルナビはドロワーへ移動。
- **SP・PC の違い**: PC は 3 領域を横並び、SP は [ハンバーガー | ロゴ | カート] に圧縮。
- **オプションフラグ**: `sticky on/off`、`カートバッジ数量`、`検索アイコン → 検索バー展開の有無`。
- **スニペット**: `assets/base-header.html` をそのまま使用。

## 2. global-nav / mega-menu
- **役割**: 大・中・小カテゴリおよびブランド/特集への入口。
- **構成**: `wf-gnav__item`（1 次）+ `wf-mega`（hover パネル、グリッドで下位リンク）。
- **状態・動作**: **PC=hover 時にアコーディオン（メガメニュー）展開**。SP=ドロワー内部のアコーディオン（＋/－）。
- **オプションフラグ**: パネルグリッドの列数（2/3/4）、ブランドはロゴ画像型 / カテゴリはテキスト型。
- **マッピング注意**: 実装 ecbeing はアンカーベース（`#block_globalnav_category` + `とじる` close）。company-rules 参照。

## 3. hamburger-drawer
- **役割**: SP 専用の全体メニュー。
- **構成**: `wf-hamburger`（トリガー）→ `wf-drawer`（左側スライド）+ `wf-overlay`。
- **状態・動作**: クリック時に左→右へスライドイン（.28s）。内部項目はアコーディオン。オーバーレイ/close で閉じる。
- **オプションフラグ**: スライド方向（左/右）、幅（デフォルト 84%）、階層の深さ（2〜3 段）。

## 4. hero-slider
- **役割**: 最上部のビジュアル。シーズン/キャンペーン訴求。
- **構成**: `wf-box--hero` 1 枚 + 左右矢印 + インジケーター（点）。
- **状態・動作**: 自動スライド/スワイプ。ワイヤーでは静的 1 枚 + 注釈で枚数を表記。
- **オプションフラグ**: スライド枚数、自動再生 on/off、インジケーターの有無。

## 5. category-grid
- **役割**: カテゴリアイコンタイルのグリッド。Top・リスト下部で共通。
- **構成**: `wf-grid--5/6` + 各タイル `wf-box--img`（アイコン）+ ラベル。
- **SP・PC の違い**: PC 5〜6 列 → SP 2〜3 列に自動で折り返し。
- **オプションフラグ**: 列数、アイコン型/テキスト型。

## 6. ranking-tab
- **役割**: カテゴリ・性別ごとの人気順表示。
- **構成**: タブヘッダー（カテゴリ/MENS・WOMENS）+ アクティブタブの `product-carousel`。
- **状態・動作**: タブクリック時に該当カルーセルへ切り替え。各カードに順位バッジ（①②③）。
- **オプションフラグ**: タブ軸（カテゴリ/性別/地域）、表示件数、順位バッジ on/off。

## 7. product-card
- **役割**: 商品 1 件の最小単位。カルーセル・グリッド・ランキングで共通。
- **構成**: サムネイル（`wf-card__thumb`）+ バッジ + お気に入り + カテゴリラベル + 商品名 + 価格。
- **状態・動作**: hover 時に Quick view / 2 番目の画像（オプション）。品切れ時はオーバーレイ。
- **オプションフラグ**: `NEWバッジ`、`SALE(定価取り消し線+割引価格+OFF%)`、`税込 表記`、`お気に入り♡`、`Quick view`、`品切れ`。
- **根拠**: Regal で `定価→30%OFF→割引価格` パターンを確認 → `wf-card__price--sale` + `<del>` を使用。

## 8. product-carousel / product-grid
- **carousel**: `wf-carousel`（横スクロール）。Top の「今売れた/おすすめ/新着」。
- **grid**: `wf-grid--4`（PC）/ `--2`（SP）。リストページ本文。
- **オプションフラグ**: 列数、「もっと見る」more ボタン、表示件数。

## 9. breadcrumb
- **役割**: 階層位置の表示（リスト・詳細の上部）。
- **構成**: `wf-breadcrumb` + `<span>`（＞ 区切り）。
- **オプションフラグ**: ホームアイコンの有無、最大階層。

## 10. filter / sort-bar
- **役割**: リストページの絞り込み。
- **構成**: `wf-filter`（左サイド、グループ別チェック）+ `wf-sortbar`（並び替えセレクト + 表示件数）。
- **SP・PC の違い**: PC=左側固定サイド。**SP=上部「絞り込み」ボタン → ドロワー/モーダル**。
- **オプションフラグ**: フィルター軸（価格/色/サイズ/ブランド）、並び替え（新着/人気/価格）、ビュー切り替え（グリッド/リスト）。

## 11. pagination
- **構成**: `wf-pagination`（番号型 + prev/next）。現在ページは `is-current`。
- **オプションフラグ**: 番号型 / 「もっと見る」（無限ロード型）/ ハイブリッド。

## 12. gallery (詳細)
- **構成**: `wf-gallery__main`（大）+ `wf-gallery__thumbs`（サムネイル列）。
- **状態・動作**: サムネイルクリック時にメインを差し替え / 拡大ズーム。
- **オプションフラグ**: サムネイル位置（下部/左側）、ズーム、枚数。

## 13. variant-selector (詳細)
- **役割**: サイズ・色・数量などの SKU 選択。
- **構成**: `wf-variant` グループ + `wf-chip`（選択肢）+ 在庫表示。
- **オプションフラグ**: 軸（色/サイズ/数量）、チップ型/ドロップダウン型、品切れチップ disabled、サイズガイドリンク。
- **根拠**: Regal=サイズ軸が必須 / Feiler=柄・色 軸 / DW mall=のし・配送日 などの食品オプション。

## 14. cta (詳細)
- **構成**: `wf-cta`（カートに入れる）+ `wf-cta--sub`（お気に入り/今すぐ購入）。
- **状態・動作**: 品切れ時は disabled + 入荷お知らせ に切り替え。
- **オプションフラグ**: 即時購入の有無、お気に入り、再入荷通知。

## 15. topics-banner
- **役割**: 特集/キャンペーンのバナータイル群。
- **構成**: `wf-grid--3/4` + `wf-box--img` タイル + more。
- **オプションフラグ**: 列数、タイトルの有無。

## 16. info-list
- **役割**: ニュース・お知らせのリスト。
- **構成**: 日付 + タイトル行の繰り返し + more。
- **オプションフラグ**: カテゴリタブ、表示件数。

## 17. footer
- **構成**: 4 列リンク群 + 法的表示 + SP/PC 切り替え + コピーライト。
- **スニペット**: `assets/base-footer.html`。
- **オプションフラグ**: 列数、SNS、決済手段バナー。

## 18. cookie-bar
- **構成**: 下部固定バー + 同意ボタン。個人情報を優先（非必須は拒否をデフォルト）。
- **オプションフラグ**: 位置（下部/モーダル）。
