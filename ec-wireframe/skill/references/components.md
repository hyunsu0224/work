# components.md — 컴포넌트 사전

와이어프레임을 조립하는 "블록 어휘집". 각 컴포넌트는 `wireframe.css`의 `wf-*` 클래스로 렌더링한다.
페이지 제작 시 여기서 블록을 꺼내 `page-templates.md`의 순서대로 배치한다.

> **표기 규약**
> - 상태·인터랙션은 회색박스 위에 `<span class="wf-note">…</span>` 주석으로 명시한다.
> - 옵션은 각 컴포넌트의 `옵션 플래그`에서 지시서로 on/off 한다.
> - 이미지 자리는 반드시 `wf-box wf-box--img`(대각선)로 표시 → 실장 시 교체 지점이 한눈에 보임.

---

## 목차
1. header (헤더)
2. global-nav / mega-menu (글로벌 내비 + 메가메뉴)
3. hamburger-drawer (SP 드로어)
4. hero-slider (히어로 캐러셀)
5. category-grid (카테고리 그리드 내비)
6. ranking-tab (랭킹 탭)
7. product-card (상품 카드)
8. product-carousel / product-grid
9. breadcrumb (빵부스러기)
10. filter / sort-bar (리스트 필터·정렬)
11. pagination
12. gallery (상세 이미지 갤러리)
13. variant-selector (사이즈/색 등 선택)
14. cta (카트/구매 버튼)
15. topics-banner (특집 배너군)
16. info-list (뉴스/인포)
17. footer (푸터)
18. cookie-bar

## 1. header
- **역할**: 사이트 최상단 고정. 브랜드 인지 + 전 페이지 공통 내비게이션 진입점.
- **구성**: 유틸리티내비(가이드/FAQ/문의/회원) · 로고 · 글로벌내비 · 회원액션(검색/즐겨찾기/마이페이지/카트뱃지).
- **상태·동작**: PC=sticky 고정. SP=햄버거만 노출, 유틸·글로벌내비는 드로어로 이동.
- **SP·PC 차이**: PC는 3영역 가로 배치, SP는 [햄버거 | 로고 | 카트] 압축.
- **옵션 플래그**: `sticky on/off`, `카트뱃지 수량`, `검색 아이콘 → 검색바 전개 여부`.
- **스니펫**: `assets/base-header.html` 그대로 사용.

## 2. global-nav / mega-menu
- **역할**: 대·중·소 카테고리 및 브랜드/특집 진입.
- **구성**: `wf-gnav__item`(1차) + `wf-mega`(hover 패널, 그리드로 하위 링크).
- **상태·동작**: **PC=hover 시 아코디언(메가메뉴) 전개**. SP=드로어 내부 아코디언(＋/－).
- **옵션 플래그**: 패널 그리드 열수(2/3/4), 브랜드는 로고 이미지형 / 카테고리는 텍스트형.
- **맵핑 주의**: 실장 ecbeing은 앵커 기반(`#block_globalnav_category` + `とじる` close). company-rules 참조.

## 3. hamburger-drawer
- **역할**: SP 전용 전체 메뉴.
- **구성**: `wf-hamburger`(트리거) → `wf-drawer`(좌측 슬라이드) + `wf-overlay`.
- **상태·동작**: 클릭 시 좌→우 슬라이드 인(.28s). 내부 항목은 아코디언. 오버레이/close로 닫음.
- **옵션 플래그**: 슬라이드 방향(좌/우), 폭(기본 84%), 계층 깊이(2~3단).

## 4. hero-slider
- **역할**: 최상단 비주얼. 시즌/캠페인 소구.
- **구성**: `wf-box--hero` 1장 + 좌우 화살표 + 인디케이터(점).
- **상태·동작**: 자동 슬라이드/스와이프. 와이어에선 정적 1장 + 주석으로 매수 표기.
- **옵션 플래그**: 슬라이드 매수, 자동재생 on/off, 인디케이터 유무.

## 5. category-grid
- **역할**: 카테고리 아이콘 타일 그리드. Top·리스트 하단 공통.
- **구성**: `wf-grid--5/6` + 각 타일 `wf-box--img`(아이콘) + 라벨.
- **SP·PC 차이**: PC 5~6열 → SP 2~3열 자동 접힘.
- **옵션 플래그**: 열수, 아이콘형/텍스트형.

## 6. ranking-tab
- **역할**: 카테고리·성별별 인기순 노출.
- **구성**: 탭 헤더(카테고리/MENS·WOMENS) + 활성 탭의 `product-carousel`.
- **상태·동작**: 탭 클릭 시 해당 캐러셀 전환. 각 카드에 순위 뱃지(①②③).
- **옵션 플래그**: 탭 축(카테고리/성별/지역), 표시 개수, 순위뱃지 on/off.

## 7. product-card
- **역할**: 상품 1건 최소 단위. 캐러셀·그리드·랭킹 공통.
- **구성**: 썸네일(`wf-card__thumb`) + 뱃지 + 즐겨찾기 + 카테고리라벨 + 상품명 + 가격.
- **상태·동작**: hover 시 Quick view / 2번째 이미지(옵션). 품절 시 오버레이.
- **옵션 플래그**: `NEW뱃지`, `SALE(정가 취소선+할인가+OFF%)`, `税込 표기`, `즐겨찾기♡`, `Quick view`, `품절`.
- **근거**: Regal에서 `정가→30%OFF→할인가` 패턴 확인 → `wf-card__price--sale` + `<del>` 사용.

## 8. product-carousel / product-grid
- **carousel**: `wf-carousel`(가로 스크롤). Top의 "今売れた/おすすめ/新着".
- **grid**: `wf-grid--4`(PC) / `--2`(SP). 리스트 페이지 본문.
- **옵션 플래그**: 열수, "もっと見る" more 버튼, 표시 건수.

## 9. breadcrumb
- **역할**: 계층 위치 표시(리스트·상세 상단).
- **구성**: `wf-breadcrumb` + `<span>`(＞ 구분).
- **옵션 플래그**: 홈아이콘 유무, 최대 계층.

## 10. filter / sort-bar
- **역할**: 리스트 페이지 좁히기.
- **구성**: `wf-filter`(좌측 사이드, 그룹별 체크) + `wf-sortbar`(정렬 셀렉트 + 표시건수).
- **SP·PC 차이**: PC=좌측 고정 사이드. **SP=상단 "絞り込み" 버튼 → 드로어/모달**.
- **옵션 플래그**: 필터 축(가격/색/사이즈/브랜드), 정렬(신착/인기/가격), 뷰전환(그리드/리스트).

## 11. pagination
- **구성**: `wf-pagination`(번호형 + prev/next). 현재 페이지 `is-current`.
- **옵션 플래그**: 번호형 / "もっと見る"(무한로드형) / 하이브리드.

## 12. gallery (상세)
- **구성**: `wf-gallery__main`(대) + `wf-gallery__thumbs`(썸네일 열).
- **상태·동작**: 썸네일 클릭 시 메인 교체 / 확대 줌.
- **옵션 플래그**: 썸네일 위치(하단/좌측), 줌, 매수.

## 13. variant-selector (상세)
- **역할**: 사이즈·색·수량 등 SKU 선택.
- **구성**: `wf-variant` 그룹 + `wf-chip`(선택지) + 재고표시.
- **옵션 플래그**: 축(색/사이즈/수량), 칩형/드롭다운형, 품절칩 disabled, 사이즈가이드 링크.
- **근거**: Regal=사이즈 축 필수 / Feiler=柄·色 축 / DW mall=のし·配送日 등 식품 옵션.

## 14. cta (상세)
- **구성**: `wf-cta`(カートに入れる) + `wf-cta--sub`(お気に入り/今すぐ購入).
- **상태·동작**: 품절 시 disabled + 入荷お知らせ 전환.
- **옵션 플래그**: 즉시구매 유무, 즐겨찾기, 재입고 알림.

## 15. topics-banner
- **역할**: 특집/캠페인 배너 타일군.
- **구성**: `wf-grid--3/4` + `wf-box--img` 타일 + more.
- **옵션 플래그**: 열수, 타이틀 유무.

## 16. info-list
- **역할**: 뉴스·お知らせ 리스트.
- **구성**: 날짜 + 제목 행 반복 + more.
- **옵션 플래그**: 카테고리 탭, 표시건수.

## 17. footer
- **구성**: 4열 링크군 + 법적표시 + SP/PC 전환 + 카피라이트.
- **스니펫**: `assets/base-footer.html`.
- **옵션 플래그**: 열수, SNS, 결제수단 배너.

## 18. cookie-bar
- **구성**: 하단 고정 바 + 동의 버튼. 개인정보 우선(비필수 거부 기본).
- **옵션 플래그**: 위치(하단/모달).
