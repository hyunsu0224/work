# EC ワイヤーフレーム ビルダー

ブラウザ上で EC サイトのローファイ・ワイヤーフレームを **組み立て → ライブプレビュー → HTML 出力** するツールです。色や画像は入れず、構造と配置だけを素早く確認します。

## 公開ページ
**https://hyunsu0224.github.io/work/**
アクセスにはパスワードが必要です（担当者より共有）。

## 使い方
アクセス後、画面右上の **❓ ガイド** に基本操作をまとめています。おおまかな流れ：

1. 上部で **ページ種別**（TOP／一覧／詳細／カート／マイページ／LP）を選ぶ
2. 左パネルの **コンポーネント** を追加・並べ替え・編集
3. 右側で **プレビュー** を確認
4. **⬇ ダウンロード** または **⧉ HTMLコピー** で書き出し

スライダー・タブ・ギャラリー・FAQ・アニメーションは、書き出したファイルでもそのまま動作します。

## 要望・リクエスト
追加・改善してほしいコンポーネントは、ツール内の **💬 リクエスト** ボタン（GitHub Issue）からお送りください。
